# Self-hosted Telephony Server

For detailed setup steps, please refer to the [Vocode Documentation](https://docs.vocode.dev/open-source/telephony).

## 1. Set Up the ngrok Tunnel

1. Start the ngrok tunnel by running the following command in your terminal:
   ```bash
   ngrok http 3000
   ```
2. Copy the HTTPS URL generated by ngrok (excluding the `https://` prefix).

## 2. Configure the Telephony Server with Twilio

1. Create a [Twilio account](https://console.twilio.com/) and retrieve your `account_sid` and `auth_token` from the account info section.
2. Navigate to **Phone Numbers -> Manage -> Active Numbers** in your dashboard and select the number you wish to configure.
3. Update the "A Call Comes In" Webhook URL to:
   `https://<YOUR_BASE_URL>/inbound_call`
   
   If using ngrok, it should look like: `https://asdf1234.ngrok.app/inbound_call`
4. Save the configuration.

## 3. Set Up the SIP Domain with Twilio

1. Go to **Voice -> Manage -> SIP Domains**. Click the plus icon (+) to create a new SIP domain if you haven't already.
2. Enter a **Friendly Name** and **SIP URI**.
3. Under **Call Control Configuration**, set "A Call Comes In" to **Webhook**.
4. Enter your ngrok URL with the `https://` prefix followed by `/inbound_call` (e.g., `https://your-ngrok-url/inbound_call`).
5. Ensure the HTTP method is set to **POST**.
6. Save the configuration.

## 4. Set Up Zoiper (Mobile App)

1. Download the **Zoiper** app from the App Store (iOS) or Play Store (Android).
2. Open the app and configure your SIP account using the credentials created in the previous steps.
3. You should now be able to make calls to your configured number using the Zoiper app.
