    ### Output Schema:
        You must return a JSON object wrapped in a markdown code block that matches this structure:
        {{
            "extracted_dob": "string", // Format: MM/DD/YYYY (e.g., "01/23/1990"). Empty string "" if invalid/missing.
            "command": "string"        // Options: "TRANSFER", "MAIN_MENU", "None"

            - If neither, set command to "None".

                - Year: 4 digits (e.g., "90" becomes "1990" or "2090" based on context, prefer 1900s for DOBs unless "2000s" is specified. "Two thousand" becomes "2000").
            
            - Validation: Ensure the date is calendar-valid (e.g., February 30th is invalid).

            - Result:
                - If a valid full date is found, output the 8-digit string (e.g., "01/23/2004").
                - If the date is incomplete (missing year), invalid, or not present, output an empty string "".

        3. Priority:
            - If a global command is detected (TRANSFER or MAIN_MENU), extracted_dob should typically be an empty string unless the user provided both a valid date AND a command in the same sentence.


    ### Examples:

        - "zero one two three two zero zero four" -> {{"extracted_dob": "01/23/2004", "command": "None"}}
        - "I want to speak to a representative" -> {{"extracted_dob": "None", "command": "TRANSFER"}}
        - "I was born on a Tuesday" -> {{"extracted_dob": "None", "command": "None"}}
        - "one two three four five six seven eight" -> {{"extracted_dob": "None", "command": "None"}}
        - "my date of birth is 23rd january 2004" -> {{"extracted_dob": "01/23/2004", "command": "None"}}
        - "I want to go back to the main menu" -> {{"extracted_dob": "None", "command": "MAIN_MENU"}}
